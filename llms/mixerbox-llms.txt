# MixerBox

> MixerBox ("Super-Apps to Live Easier") is a Y Combinator / Initialized Capital-backed consumer software company that ships a large family of AI assistant tools as ChatGPT plugins / GPT Actions. Each product publishes an OpenAI plugin manifest (`/.well-known/ai-plugin.json`) and an OpenAPI 3.1 spec (`/.well-known/openapi.json`). Authentication is service-level (`service_http`) or `none`; there is no end-user OAuth API surface (except MixerBox Calendar's Google Calendar linkage).

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public plugin manifests and OpenAPI specs.

## APIs (ChatGPT plugins / GPT Actions)

- [MixerBox OnePlayer](https://www.mbplayer.com/openapi.json): Music, podcasts, and videos — playlists by genre/mood, search music/podcasts.
- [MixerBox Podcasts](https://podcasts.mixerbox.com/.well-known/openapi.json): Podcast discovery — popular/by-category podcasts and episodes, search.
- [MixerBox Weather](https://weather.mixerbox.com/.well-known/openapi.json): Real-time worldwide weather and forecasts.
- [MixerBox Calendar](https://calendar.mixerbox.com/.well-known/openapi.json): Google Calendar assistant — list/add events, free-time lookup, authorize/logout.
- [MixerBox Translate](https://translate.mixerbox.com/.well-known/openapi.json): Translation, explanation, and language-learning tasks.
- [MixerBox ImageGen](https://imagegen.mixerbox.com/.well-known/openapi.json): Text-to-image generation.
- [MixerBox PhotoMagic](https://photomagic.mixerbox.com/.well-known/openapi.json): Image super-resolution and editing.
- [MixerBox ChatPDF](https://chatpdf.mixerbox.com/.well-known/openapi.json): Upload a PDF and query its contents.
- [MixerBox Scholar](https://scholar.mixerbox.com/.well-known/openapi.json): Academic paper upload/query and abstract search.
- [MixerBox QR](https://qr.mixerbox.com/.well-known/openapi.json): Generate QR codes from a URL.
- [MixerBox Diagrams](https://diagrams.mixerbox.com/.well-known/openapi.json): Render diagrams (e.g. mermaid) to images.
- [MixerBox Prompt Pro](https://promptpro.mixerbox.com/.well-known/openapi.json): Optimize / rephrase prompts.
